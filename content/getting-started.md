# 开始使用【围读】

## 新写一稿

在成功登录且成功配置完 AI 设置项后，可在界面中点击「新开一稿」开始新的写作项目开始工作流。

![图1：新开一稿](/docs-assets/fig1-new.png)

点击后会出现新写一稿的初步设置界面，此处的设置均可在未来进行调整修改：

![图2：新开一稿界面](/docs-assets/fig2-new-form.png)

此界面包含以下设置项：

1. **标题**：设置该写作项目的标题。在项目内导出文件时会以该标题命名。
2. **从哪里开始**：【围读】可以从写作流程三个不同环节开始，对应使用的提示词不同。此处开始后本项目内无法更改。
3. **想法**：即你想要生成内容的初始提示词 / 想法 / 大纲 / 稿件。
4. **字数目标下限 / 目标上限**：这里设置最终成文的目标字数（大纲不受此字数影响），可在项目内随时修改。

确认完毕后，点击开始按钮开始本写作项目。

## 从想法 / 大纲开始

当选择从想法 / 大纲开始后，会进入到「想法 → 大纲」的界面。

![图3：从想法或大纲开始](/docs-assets/fig3-idea-outline.jpeg)

进入后，若从想法开始，则想法会显示在左侧；从大纲开始，则大纲会显示在右侧。

若从想法开始，则点击左侧下方【生成大纲】按钮，即可在右侧窗口内根据想法生成大纲内容。

若从大纲开始，则点击底部【确认本次定稿】后，进入「大纲 → 稿件」的设置页面。

在该页面中，即可开始使用【AI 读者】对生成 / 配置的大纲进行阅读，随后提出自己的意见。操作方法为点击读者右侧的【请未屏蔽的读者一起看】按钮。点击后对应读者将开始阅读。顶部出现当前进度状态栏。所有读者阅读完毕后，各读者意见将显示在读者区下方，如图：

![图4：读者意见](/docs-assets/fig4-reader-feedback.png)

你可以展开对应的读者意见查看该读者意见的具体内容。然后你可以选择是否采纳该读者意见。选择你要采纳的读者意见后，才可点击左下角【按已有读者意见改一版】按钮。也可对该读者意见点击讨论按钮提出你想调整的内容。

当读者意见你决定采纳并根据读者意见修改大纲内容时，点击左下角【按已有读者意见改一版】按钮，大纲将根据你采纳的读者意见进行修改。顶部出现当前进度状态栏，直到大纲修改完毕，大纲窗口对应刷新。新的大纲你可以再让读者进行阅读再次进行修改操作。

在读者意见之外，你也可以发送自己的意见进行修改，即底部你的修改意见区域。输入内容后点击【按这条意见改一版】按钮，大纲也同样会根据你的意见进行修改。

直到你确定这个大纲没有问题后，点击底部【确认本次定稿】，进入「大纲 → 稿件」的设置页面。

## 大纲 → 稿件 / 从完整稿件开始

![图5：从润色 / 完整稿件开始](/docs-assets/fig5-polish.jpeg)

「大纲 → 稿件」页面和「从完整稿件 → 润色」界面内容基本一致。同样为左侧输入大纲 / 稿件内容，右侧 AI 根据输入内容和你 / 【AI 读者】修改意见输出成果。

要注意的是：第一次输出内容时，很可能输出的成果字数也不符合要求，也不符合大纲设计。因此该界面底部单独增加了【结构质检】区域。若发现字数不符合要求也不符合大纲设计时，可以先点击这里的【跑一次结构质检】按钮。结构质检在阅读完毕内容后会给出一个反馈意见。

此时点击按质检意见再改后，新稿件基本可以满足符合字数和大纲要求了。

但是一般字数要求较多（大于 3000）的情况时，AI 新输出内容就算满足了字数要求，很可能也会有注水现象。这时要求【AI 读者】审核稿件并进行修改的流程就变得尤为重要。因此强烈建议在结构质检后输出的稿件一定要让 AI 读者阅读一遍后再修改一版，来达到最好的效果。

【AI 读者】修改和自己修改的操作流程与前文所描述的方法一致，这里不再过多赘述。

当最终定稿确认完毕后，可点击右上角的导出正文按钮。最终正文将会直接导出一个 md 文件供你下载。之后再点击定稿会进入润色流程。

该写作工程将持续留在你的面板中，随时可点开也随时可对中间流程进行修改创作。
